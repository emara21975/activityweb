# نظام إدارة الأنشطة الطلابية — نسخة ويب Next.js

> الإصدار: 2.0 — 2026-09-24 | الحالة: مواصفات تنفيذ معتمدة | النطاق: مدرسة واحدة، مستخدمون متعددون، VPS، قاعدة جديدة فارغة.
> هذه الوثيقة تحل محل النسخة المكتبية المقابلة. لا تنطبق أي تعليمات تخص PySide6 أو SQLite أو Portable EXE أو التشغيل دون إنترنت على نسخة الويب.

## عن المشروع
مواصفات مشروع ويب Fullstack Next.js لمدرسة واحدة، متعدد المستخدمين والأدوار، مستضاف على VPS خاص مع PostgreSQL جديدة وفارغة. الملفات الثمانية هنا وثائق تنفيذ متكاملة **وليست كود تطبيق جاهزًا**. تحتفظ بوظائف النسخة المكتبية وتستبدل اعتماد Windows/EXE/PySide6/SQLite ببنية ويب خادمية.

## اقرأ بهذا الترتيب
1. `PRD.md` الوظائف والنطاق والأدوار.
2. `BUSINESS_RULES.md` التعريفات الحسابية والثوابت.
3. `DATABASE_SCHEMA.md` الجداول والقيود والمستخدمون.
4. `TECHNICAL_STACK.md` المكدس والأمان والنشر.
5. `UI_UX_SPECIFICATION.md` الشاشات والمسارات والـRTL.
6. `IMPLEMENTATION_ROADMAP.md` المراحل وبوابات القبول.
7. `GEMINI.md` تعليمات الوكيل التنفيذي.

## قرارات نهائية
مدرسة واحدة؛ حسابات متعددة بصلاحيات مختلفة؛ VPS خاص؛ قاعدة بيانات جديدة فارغة؛ Excel اختياري للاستيراد/التصدير فقط؛ لا نسخ تلقائي لبيانات التطبيق المكتبي؛ لا وضع offline أو Portable EXE. العام الدراسي وبيانات المدرسة تُضبط عبر إعداد أولي آمن؛ التصنيفات التسعة والأذون والأدوار تُزرع افتراضيًا دون بيانات طلاب.

## بداية التطوير (بعد إنشاء كود التطبيق)
تثبيت Node.js LTS المتوافق وPostgreSQL، إعداد `.env` من `.env.example` دون وضع أسرار في Git، إنشاء DB ومستخدم محدود، ثم `npm ci` و`npx prisma migrate dev` في التطوير و`npm run dev`. على VPS: `npx prisma migrate deploy` ثم `npm run build` وتشغيل الخدمة خلف Nginx/Caddy مع HTTPS. أوامر npm تفترض أن وكيل التطوير أنشأ package.json/scripts والحزم اللازمة؛ هذه الحزمة لا تتضمنها.

## نشر وأمان
لا تعرض PostgreSQL أو ملفات المرفقات للإنترنت؛ خزّن الأسرار خارج المستودع؛ أنشئ أول مدير بأمر one-time آمن؛ اختبر الصلاحيات على كل endpoint؛ أنشئ نسخة احتياطية لقاعدة البيانات والمرفقات قبل كل migration مهمة؛ تحقق من استعادة النسخ دوريًا. يجب أن تكون قاعدة الإنتاج خالية من الطلاب والأنشطة والمشاركات التجريبية.

## معيار التسليم
تعمل رحلة طالب → نشاط → مشاركة → تقارير/إحصائيات من المتصفح؛ تطابق UI/PDF/Excel؛ جلسات وصلاحيات حقيقية؛ مرفقات وتنزيلات آمنة؛ نسخ واستعادة مجرّبة؛ نشر VPS مستقر؛ اختبارات موثقة.
