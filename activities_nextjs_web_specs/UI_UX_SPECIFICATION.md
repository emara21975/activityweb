# مواصفات الواجهة وتجربة المستخدم — Web RTL

> الإصدار: 2.0 — 2026-09-24 | الحالة: مواصفات تنفيذ معتمدة | النطاق: مدرسة واحدة، مستخدمون متعددون، VPS، قاعدة جديدة فارغة.
> هذه الوثيقة تحل محل النسخة المكتبية المقابلة. لا تنطبق أي تعليمات تخص PySide6 أو SQLite أو Portable EXE أو التشغيل دون إنترنت على نسخة الويب.

## مبادئ التصميم
واجهة عربية RTL أولًا، هوية عنابية قطرية مع أبيض ورمادي فاتح ولمسات ذهبية محدودة، جداول قابلة للقراءة، تنقل واضح، لا محاكاة بصرية لورقة Excel. تصميم responsive يبدأ من Desktop 1366×768 ويعمل على 1920×1080 والتابلت والهاتف؛ في الهاتف تتحول الجداول إلى بطاقات أو تمرير أفقي واضح. تباين مناسب، لوحة مفاتيح، focus مرئي، aria labels، رسائل خطأ عربية.

## هيكل التطبيق
صفحة دخول منفصلة؛ داخل النظام Header: شعار المدرسة، الاسم، العام الحالي، اسم المستخدم وقائمة الحساب والخروج؛ Sidebar يمينًا: الرئيسية، الطلاب، الأنشطة، تسجيل المشاركات، التقارير، الإحصائيات، الاستيراد والتصدير، النسخ الاحتياطي، الإعدادات، المستخدمون والصلاحيات، سجل العمليات. تُخفى العناصر غير المصرح بها للتجربة فقط، مع فحص خادمي مستقل. Breadcrumbs، مؤشر تحميل، حالات فارغة وخطأ ونجاح، تنبيه تغييرات غير محفوظة.

## لوحة التحكم
شريط فلاتر عام/فترة/صف/شعبة مع تطبيق وإعادة تعيين، بطاقات الإجمالي والمشاركين وغير المشاركين والأنشطة والمشاركات والنسبة والقطريين وغير القطريين، أحدث الأنشطة، إجراءات سريعة. تعرض كل بطاقة عنوانًا وتعريفًا واضحًا ورابط تفصيل مصرح به؛ لا تخلط المشاركات بالطلاب الفريدين.

## صفحة الطلاب
شريط: إضافة طالب، استيراد Excel، تصدير، تحديث (حسب الإذن). فلاتر العام والصف والشعبة والجنسية/مجموعة الجنسية والحالة وبحث الاسم/الرقم الأكاديمي. بطاقات تتبع الفلتر: عدد الطلاب، القطريون، غير القطريين، بيانات الجنسية الناقصة؛ **لا بطاقات مشاركة في هذه الصفحة**. جدول مرقم تسلسليًا حسب الترتيب والصفحة: م، الرقم الأكاديمي، الاسم، الجنسية، الصف، الشعبة، الحالة، إجراءات العرض/التعديل/الأرشفة؛ pagination server-side. ملف الطالب يعرض مشاركاته في قسم منفصل.

## شاشة الأنشطة والمشاركات
قائمة الأنشطة: التاريخ، الاسم، التصنيف، المشاركون، قطري، غير قطري، الحالة، إجراءات. نموذج نشاط مع التحقق من الاسم والتصنيف والتاريخ والعام؛ رفع المرفقات بعد حفظ النشاط أو عبر معاملة عمل واضحة. شاشة المشاركات: اختيار النشاط → الصف → الشعبة → قائمة الطلاب مع checkboxes وبحث وتحديد الكل/إلغاء الكل → معاينة العدد → حفظ؛ رسائل النجاح والتكرار والتعارض المتزامن؛ لا تختفي الاختيارات عند خطأ تحقق قابل للتصحيح.

## التقارير والإحصائيات
صفحة اختيار نوع التقرير، شريط فلاتر متسق، جدول واضح، أزرار عرض/طباعة/PDF/Excel بحسب الإذن، أرقام قابلة للنقر لتفصيل السجلات. التقرير الرسمي يحتوي الأعمدة: الفئة، قطري، غير قطري، الإجمالي، نسبة المشاركين، نسبة القطريين، نسبة غير القطريين؛ أسفله المجاميع المميزة بوضوح. تظهر الفترة والعام ومصدر البيانات ووقت التوليد والشعار في الطباعة والتصدير. عدم وجود بيانات يعرض 0 أو — وفق قاعدة التقرير وليس شاشة فارغة مبهمة.

## الإدارة والعمليات الحساسة
إدارة المستخدمين: جدول، إنشاء حساب، تفعيل/تعطيل، تعيين دور، تغيير كلمة مرور بإجراء آمن؛ إدارة الأدوار: مصفوفة أذون واضحة وتحذير قبل التغيير؛ سجل العمليات read-only. الاستعادة تعرض تحذيرًا وتطلب تأكيدًا إضافيًا وتعرض نتيجة التحقق دون تسريب مسارات الخادم. رفع Excel يعرض معاينة الصفوف والأخطاء قبل زر اعتماد مستقل.

## حالات الواجهة وقبولها
Loading skeleton، Empty state مع إجراء مناسب، Unauthorized 403، Not Found 404، خطأ 500 برسالة غير تقنية، Session expired مع إعادة دخول، unsaved changes، toast نجاح، تأكيد أرشفة، عرض حجم الملف المسموح. اختبار keyboard/RTL/responsive والطباعة، وحفظ الفلاتر في URL query عند الملاءمة دون بيانات شخصية حساسة.
